# Windows 接收方 Agent 交接

本说明适用于仓库的 `windows/` 子目录，请先阅读仓库总 README，再从该目录执行安装与测试。

可以直接把下面这段发给接收电脑上的 Agent：

> 请帮我安装这个 Windows 版关爱通自动领取工具。先读 README.md、WINDOWS_VALIDATION.md 和代码，确认系统为 Windows 10/11，Chrome、uv 可用。
>
> 这是 Windows 实机待验证的候选版本，不要把打包者在其他系统完成的42项测试和XML校验当成此电脑已经运行成功。先运行 install.cmd，仅准备环境，不先启用定时。
>
> 使用本人普通 Windows 桌面账号。遇到同名/未知运行目录或任务，先告诉我，不覆盖、不提权绕过公司策略。不要修改全局执行策略，不关闭安全软件。
>
> 打开专用 Chrome，由我人工登录；不要索要、打印或复制密码、验证码和 Cookie。识别领取页后保存并自动关闭。再由我确认是否授权本站点使用真实定位，不使用虚拟坐标，也不复制其他人的定位同意。
>
> 先运行“仅检查.cmd”，核对零次点击。定位能力和原生弹窗需在本机验证。未经我另外同意，不实际点击领取、不让电脑睡眠/关机，也不直接运行任务做有副作用的测试。
>
> 检查通过且我确认后，再用“启用定时.cmd”注册任务：每天本机时间20:30、仅我已登录时、最低权限、pythonw隐藏启动、不唤醒、不补跑。手动入口允许20:30到次日00:00前，正常流程最多5次，成功或阻断时停止。
>
> 最后说明：安装与测试结果、哪些Windows原生项目尚未验证、是否已启用任务、7个入口、日志路径和停用方式。不要将 `ready`、退出码0或点击次数说成到账成功。

## 接收方注意

- Agent 的非交互命令工具优先运行 `uv run --no-project --python 3.13 install.py --prepare-only`，不要直接执行会 `pause` 的人工 `.cmd` 入口。启用/停用/查询也可分别传入 `--enable`、`--disable`、`--status`；启用前仍需本人确认。

- 源码包只有 `install.cmd` 是启动入口；其他 `.cmd` 文件在安装时按本机路径生成。
- 运行目录在 `%LOCALAPPDATA%\GuanaitongAutoClaim`，与打包者电脑没有共享登录态。
- 已授权定位也不保证系统/网络能返回位置。打不开 System 电源事件时，自动任务会返回 `power_state_unknown`；手动模式不读电源历史。
- 跨天 Cookie 可能失效，脚本没有自动续期保证。可在每天接近领取时间时人工确认登录；“保存已有Cookie”不等于延长它的服务器有效期。
- `.cmd` 人工入口会显示终端，正常20:30任务不会用该终端入口；它直接启动 `pythonw.exe`。
- 安装器默认不启用任务。更新时重新运行 `install.cmd`，之后检查现有任务状态；不要假设复制源码会自动更新运行副本。
- 许可证尚未选择，公开发布前还需维护者处理授权与合规事项。
